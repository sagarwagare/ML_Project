
# 🔍 ML Model Comparator & Tutorials with Chatbot

An interactive web-based application for comparing machine learning regression algorithms, learning ML concepts through tutorials, and engaging with an AI chatbot for real-time Q\&A. Built using **Flask (Python)** for the backend and **HTML/CSS/JS ** for the frontend.

---

## 🌟 Features

* **AI Comparator**: Compare performance (MSE, MAE, R²) of two ML regression models on selected datasets.
* **Tutorial Section**: Learn core ML concepts like clustering, regression, anomaly detection, and dimensionality reduction.

---

## 🛠️ Technologies Used

* **Frontend**: HTML, CSS,  JavaScript
* **Backend**: Flask (Python)
* **ML Libraries**: scikit-learn, LightGBM, XGBoost
